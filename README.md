# Katalog Produk

Halaman katalog produk dengan fitur pencarian, filter kategori, sorting harga, dan pagination. Dibuat dengan HTML, CSS, dan JavaScript.

## Fitur

- Menampilkan daftar produk dalam bentuk kartu
- Search berdasarkan nama produk
- Filter berdasarkan kategori
- Sorting berdasarkan harga (termurah / termahal)
- Pagination (6 produk per halaman)
- Tombol reset
- Tampilan responsive

## Cara Menjalankan

1. Clone repository:
   git clone https://github.com/USERNAME/katalog-produk.git
2. Masuk ke folder:
   cd katalog-produk
3. Buka `index.html` di browser (atau pakai Live Server di VS Code)

## Demo

https://rizkilabs.github.io/katalog-produk

## Struktur Proyek

- `index.html`: struktur halaman
- `style.css`: tampilan
- `script.js`: data produk dan logika search, filter, sort, pagination
